# The Interactive Extension Showcase

Every block in this book is powered by a **Bücher extension**: a pluggable, sandboxed widget that lives inside ordinary Markdown. Read the chapters in order, interact with every block, and watch your progress persist — close the app, reopen it, and your work is still here.

What to try:

- Zoom and pan the diagrams, drag the function sliders, and play the algorithm traces.
- Solve the exercises: passing the tests, the puzzle, or the query **marks the exercise solved automatically**.
- Open **Settings → Extensions** to toggle extensions and inspect the AI authoring skill each one exposes. With extensions enabled, *Import with AI* and *Propose a patch* know how to write these blocks for you.

Use the frame controls on any block: the chevron collapses it, the circular arrow resets its state, and `{}` shows the exact YAML payload the author wrote.
